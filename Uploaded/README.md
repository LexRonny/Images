# Uploaded

This folder is for AI-generated images you want to archive.

This README is a placeholder so Git tracks the Uploaded folder. Add your image files here (e.g. .png, .jpg, .webp). If you plan to store large images or many binary files, consider using Git LFS: https://git-lfs.github.com/

To upload images via the web UI: go to this folder in the repo and click Add file → Upload files, or upload from your local clone with git and push.
